# 折纸拓扑与三维几何引擎(Phase 03)

## 1. 架构总览

Phase 03 采用**并行拓扑层**策略:现有折叠引擎(`engine.ts`)与全部机型折序保持不变,新增纯逻辑模块在其上提供拓扑、来源追踪、统一 3D 输出与历史持久化,避免一次性重写带来的回归风险。

| 模块 | 职责 | 说明 |
|---|---|---|
| `src/fold/topology.ts` | 面片拓扑追踪 | 与引擎同一 `splitFold` 剖分与层叠顺序;面片 ID/来源链/层叠索引/折痕记录;面积守恒 |
| `src/fold/geometry-out.ts` | 统一 3D 几何输出 | 面片顶点/法向/面积/层序/来源面片 ID + 包围盒 + 三角网格;兼容 `viewFaces3d` 与 `massFaces3d` 两条既有来源 |
| `src/fold/geometry-constants.ts` | 统一几何容差 | 全部阈值集中定义(线段 1 µm、面积 1 µm²、裁剪 0.1 nm、内部 0.1 µm、匹配 10 µm),模块间不再各自定义 |
| `src/fold/history-io.ts` | 折叠会话持久化 | 版本化编码/解码,拒绝损坏与越界存档 |

## 2. 已实现能力(3.1 基线 + Phase 03 增强)

- 多边形半平面裁剪、反射、谷/山折、顶层折叠、区域折叠(`region`)、塞入(`tuckUnder`)、翻面(`flip`)、展开(`unfold`/`unfoldToStep`)、一步多子操作、展翼投影(`openToStep`)。
- **新增**:显式翼根折线 `openRoot`,允许倾斜翼根(3.10);统一 3D 几何输出(3.11);拓扑稳定 ID 与来源链(3.3);会话序列化(3.13);复杂度上限护栏(3.16)。
- 折痕图:长度/类型/预折标记/交点/Maekawa 差值/左右对称(3.12,既有能力 + 测试覆盖)。

## 3. 已验证不变量(全部机型 × 纸张)

- 每步面积守恒 = 纸张面积;最终质量 = 面积 × gsm(Phase 02 测试)。
- 拓扑面片数 = 引擎层数(7 机型全部一致);面片 ID 唯一;重放确定性。
- 3D 面片面积之和 = 纸张面积(水平翼根路径精确;倾斜翼根投影为文档化近似 ≤0.2%)。
- 撤销/重做/跳步/会话往返;撤销后新操作清理重做历史。
- 随机合法折序列(固定种子 20261127,12 组)面积守恒与确定性;非法折叠抛错且不破坏既有状态。
- 镜像构型面积/展长/AR 不变(2.2 测试);平移不变量。

## 4. 明确不支持/近似的能力(3.8/3.9 范围声明)

- **任意层序求解**:层序仍用引擎的线性层叠索引;纸袋/锁头的真实局部前后关系为近似,不作全局保证。复杂层序操作会被引擎显式拒绝(`tuckUnder` 越界等),不会静默丢纸。
- **完整碰撞检测**:零厚度模型下允许符合层序规则的重合面片;非法穿透/铰链矛盾不做通用检测(记录为 Phase 04 及以后)。
- **任意自由折痕(画折痕即折)**:受限自由折(Phase 03 特性阶段)已支持半平面折 + 现有原语;任意层序与曲面折叠仍不支持。
- **倾斜翼根投影精度**:`deploySlopedWings` 的截面裁剪为近似(≤0.2%),不影响既有 7 机型(均走精确水平翼根路径)。
- **动画与几何一致性**:折叠动画由 `animate.ts` 按同一反射变换插值,终点与 `apply` 结果一致(既有测试 `fold-animate`/`fold-geometry3d` 覆盖)。

## 5. 性能

拓扑追踪单次成本 0.23–0.99 ms(7 机型,20 次均值);面片上限 4000(超出明确抛错)。渲染 3D 网格由 `foldedGeometry3D` 生成,供 Three.js 视图消费。

## 6. 版本与迁移

`FOLD_ENGINE_VERSION = 5` 未变:现有折序几何逐位一致(拓扑层只读不改)。新增 `openRoot` 为兼容扩展(缺省行为不变)。机型迁移验证:7 机型拓扑面片数/3D 面积/层数快照由测试锁定(16/32/76/32/106/32/46 片)。
