# 纸张材料、折叠精度与调校(Phase 04)

## 1. 三层数据模型(4.1)

`规格(PaperSize) × 材料(PaperMaterial) × 克重(gsm) = 纸张实例(PaperInstance)`

- **规格**:`src/paper/papers.ts`,内置 A4 / US Letter / 正方形 / A5 / B5 / A3 / A6,物理尺寸以米保存;`instance.ts` 另支持自定义矩形(80–450 mm × 80–650 mm,50–160 gsm)及范围校验。
- **材料**:`src/paper/material.ts`,8 种材质(复印纸/高挺激光纸/铜版纸/折纸纸/新闻纸/牛皮纸/书写纸/轻质薄纸),各自记录用途、克重范围、厚度系数、MD/CD 杨氏模量、表面粗糙度代理、折痕保持代理、来源与可信度(`literature-range` / `estimated`)。
- **实例**:`makeInstance(size, material, gsm)` / `customInstance(w,h,material,gsm)`;质量 = 面积 × gsm;`checkFoldCompatibility` 在折叠开始前用引擎重放验证机型 × 纸张,避免折完才发现无效几何。

同一尺寸不再绑定固定材料:材料是独立维度,分享/比赛/回放携带材料。

## 2. 折层厚度与结构刚度(4.4–4.5)

- `src/paper/stack.ts`:单张厚度来自材料参数;叠层厚度 = n × t × 压实系数(0.85,经验中值);折痕处厚度 = n·t + 折痕圆角附加。
- 多层结构弯曲刚度给出上下界:**完全黏合 n³·B**(上界)与**完全滑移 n·B**(下界),nominal 取几何中值;未考虑层间摩擦与折痕取向差异,误差范围随层数增大——明确标注为工程估算,不是实测。
- 零厚度模型仍是气动几何基准(兼容选项):厚度仅进入结构分析展示,未伪造未经验证的飞行效果。

## 3. 折痕误差 → 真实几何(4.6–4.7)

- 手工折叠提交时记录落点相对折痕目标的偏差,归一化为折痕端点平移偏移(`src/fold/adjustments.ts`),上限 ±4% 纸宽。
- 重放折序时把偏移施加到对应折痕线,由引擎重新剖分/反射:**误差通过真实材料分布改变重心、翼面积、对称性与气动焦点**,而不是对成绩乘系数。
- 自动演示/跳过教学不产生偏移(确定性标准折序);相同折序 + 相同偏移 → 相同几何(确定性测试)。
- **移除成绩乘数**:`FLIGHT_MODEL_VERSION` 5→6,默认路径不再把折痕质量乘到升阻上(v4/v5 乘数通道仅保留为 `legacyQualityChannel` 历史对照,不用于 gameplay)。锚点(完美折痕)逐位不变。

## 4. 折痕回弹(4.8)

`wingSpringBackDeg = 20° · (1 − creaseRetention) · (1 + 0.05·(layers−1))`,确定性经验线性模型;自然展翼角 = 90° − 回弹角。仅作为展示/调校基准,未实测前不自动改变已发布折序的几何。

## 5. 调校系统(4.10)

`src/paper/trim.ts`:左右上反角(±10° UI,±20° 模型)、后缘上翘(±8° UI,±10° 模型)、翼尖小翼(0–90°,仅几何展示)。

- 上反角:两侧投影展长/翼面积按 cosΓ 收缩,左右独立 → 不对称度;**实际改变求解器使用的展长、翼面积、展弦比**;
- 后缘:Δα0 = τ·δ,τ=0.5(薄翼襟翼效率经典近似),取全后缘上限;
- 越界调校明确拒绝;默认调校严格恒等(返回同一 Aero 对象)。
- 调校数据进入分享链接(可选字段 + 逐项校验),比赛仍锁定预设机型(调校不进入正式赛,避免非对称优势)。

## 6. 结构分析界面(4.11)

物理面板新增:左/右翼面积、对称度、峰值折层、结构刚度估计(附上下界);区分精确几何量(面积/重心/展弦比)与经验估算量(刚度/折痕利落度,标注"估算")。

## 7. 材料敏感性实测(4.12,`npm run sensitivity`)

- 克重:质量严格线性(A4 70/80/100 gsm → 质量 1.25×/1.0×/0.8×);
- 材质(A4 80 suzanne):复印纸/激光纸 60.68 m(激光被定形上界封顶为同等)、铜版 59.90、折纸 57.39、新闻 56.07、牛皮 58.22、书写 59.97——单调且可解释;
- 无拱度机型(dart)材质不影响飞行(材质通道仅作用于拱度定形),如实记录为模型局限;
- 调校(suzanne):10° 上反 69.20 m、不对称 0/10° 68.82 m(vs 默认 68.33 m),差异来自真实投影几何。

## 8. 持久化与复现(4.13)

分享链接新增可选字段:`grade`(Phase 01)、`creases`(折痕偏移)、`trim`(调校),逐项校验、缺省兼容旧链接;同一纸张+折序+调校+偏移重建等价几何。历史幽灵/正式赛 PB 仍按版本键隔离,不受后续修改影响。

## 9. 已知限制

- 厚度/刚度未直接进入气动求解(仅结构分析展示),零厚度模型仍是飞行基准;
- 折痕回弹不自动改变既有折序几何(避免未验证改动锚点);
- 调校仅进入自由模式分享,不进入正式比赛;
- 材质飞行效应只通过既有拱度定形通道(有明确上界),无拱度机型不受材质影响。
