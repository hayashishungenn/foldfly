## 2. 解析基准(A4 = 0.21×0.297 m)

- 质量:gsm × 面积 / 1000 → 80 gsm = **4.9896 g**,100 gsm = **6.237 g**(解析值,测试逐机型锁定)。
- 均匀矩形板俯仰惯量 m·h²/12(重叠层按每层质量累加);翼面并集面积不重复计受力。
-平移/镜像/旋转/单位换算不变量见 docs/COORDINATES.md 与 tests/coordinate-units.test.ts。
