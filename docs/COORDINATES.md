# 坐标系、符号约定与单位(Phase 02 / 2.2)

## 1. 四套坐标系及其关系

| 坐标系 | 轴 | 原点 / 方向 | 使用者 |
|---|---|---|---|
| 纸张/折叠坐标系 | x ∈ [0,w] 横向,y ∈ [0,h] 纵向;单位 m | 纸左上角 (0,0),**y 增大指向机尾**;机头位于 y=noseY=min(y) | fold/engine.ts、extract.ts;几何以米为单位(papers.ts 中 w=0.21 等) |
| 世界坐标系 | +x 顺风下程,+y 竖直向上,+z 投掷者右侧 | 释放点 (0, 1.5 m, 0);重力 (0,−9.81,0) | integrator.ts、Flight.samples、render/*;飞行 +x 对应纸面 **−y** 方向 |
| 机体坐标系 | n̂ 前向,r̂ 右翼向,û 机体上方 | 随偏航 ψ、俯仰 θ 旋转;v5 侧滑 β 与迎角 α 由空速在机体轴上的分解给出 | integrator.ts v5 3D 路径;见下方公式 |
| 视图/画布坐标系 | Canvas 2D 像素 (px,py),py 向下 | render/flight2d.ts:世界 x→px,世界 y→py(翻转);俯视图:世界 x→px,世界 z→py | 仅渲染,不参与物理 |

**机头方向**:纸面 −y;世界 +x(释放瞬间)。**机翼横向**:纸面 x;世界 +z=右。**高度**:世界 +y 向上,纸面无高度(平展投影)。

## 2. 角度与符号(v5 实现)

- 俯仰 θ:绕机体右轴 r̂;θ>0 = 机头上仰;发射时 θ=angle·π/180。
- 偏航 ψ:绕世界 +y;ψ>0 = 机头转向 +z(右);机体右轴 r̂=(−sinψ, 0, cosψ)。
- 横滚 φ:绕机体前向 n̂;实现中 φ>0 时升力侧倾分量取 +sinφ·r̂,横滚恢复项按 φ 与 β 的符号约定计算(见 AERO-FORMULAS §4)。
- 迎角 α:`atan2(−vbU, vbF)`,其中 vbF=空速·n̂、vbU=空速·û;α>0 = 来流从机翼下方来。
- 侧滑 β:`atan2(vbR, vbF)`;β>0 = 来流来自机体右侧。
- 力矩:俯仰力矩绕 r̂(+ 抬头),偏航绕 +y(+ 右转),横滚绕 n̂;力矩单位 N·m,角加速度 rad/s²。
- 重心 CG:纸层面积加质心(m);气动焦点 AC:四分之一弦面积加权(m);**推力/阻力方向**与相对空速相反,升力垂直于相对空速。
- 相对空速 u = v_ground − v_wind;风速 `wind>0` = 顺风(沿 +x),`crosswind>0` = 吹向 +z。

## 3. 机体轴分解公式(v5,integrator.ts)

```
n̂ = ( cosθ·cosψ,  sinθ,  cosθ·sinψ )
r̂ = (−sinψ,       0,     cosψ       )
û = (−sinθ·cosψ,  cosθ, −sinθ·sinψ )
vbF = u·n̂,  vbR = u·r̂,  vbU = u·û
α = atan2(−vbU, vbF);  β = atan2(vbR, vbF)
升力方向 l̂ = normalize(û − (û·û̂_air)·û̂_air)   // 机体上方在垂直于空速平面内的投影
合力 F = L·(cosφ·l̂ + sinφ·r̂) − D·û̂_air − S_side·r̂
```

## 4. 单位与输入转换

| 量 | 内部单位 | 输入单位 | 转换点 |
|---|---|---|---|
| 长度/位置 | m | mm(UI 纸规格显示) | papers.ts 已用 m;UI ×1000 仅显示 |
| 质量 | kg | gsm(g/m²) | extract: gsm/1000 kg/m² × 面积 |
| 角度 | rad | °(投掷台、折痕文案) | main.ts/simulate 入口 `·π/180` |
| 力/力矩 | N / N·m | — | q=½ρV²S |
| 压强/密度/黏度 | Pa / kg·m⁻³ / m²·s⁻¹ | — | ρ=1.225,ν=1.511e-5(展示用) |
| 无量纲系数 | — | — | CL/CD/AR/SM/e/Re 等 |

**输入层可用度数与 gsm,进入物理求解器前必须完成转换**(2.2 验收)。引擎内部不得再次混用角度制。

## 5. 不变量与测试基准

- 坐标平移:纸面整体平移 (dx,dy) 不改变质量、CG 相对坐标、气动属性与飞行结果(已有 `core.test.ts` 与 `geometry-invariants.test.ts` 覆盖)。
- 镜像:沿 x=w/2 镜像改变左右翼,但对称机型的几何标量(面积/展长/惯量/AR)不变;侧风符号镜像后侧向落点镜像(需新增)。
- 旋转:纸面内任意旋转会改变重力方向相对关系,**不**要求飞行不变;只要求面积/质量/惯量标量在纯旋转下守恒(需新增)。
- 单位换算:A4 210×297 mm 与 0.21×0.297 m 为同一规格;80 gsm × 0.21 m² × 0.297 m² = 4.9896 g(解析基准),100 gsm = 6.237 g。
