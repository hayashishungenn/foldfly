二、字体规范

标题:霞鹜文楷 LXGW WenKai(开源手写楷体)
二级标题:同字体,字号分层,不用粗体堆叠
正文:投掷角度、风力这些参数要用真实单位,文案要有"课堂讲义"的口吻。
数字:IBM Plex Mono → 40° · 12.0 m/s · 88.0 m · 29.2 s
批注:微旋转 −1°,像老师的红笔字。
