# 参考设计风格 — 一纸冲天 FoldFly

> 配套可视参考:[ui-reference.html](ui-reference.html)(色板 / 字体 / 线框 / 组件样式,浏览器直接打开)。

## 1. 设计概念:「作业本 × 航空图鉴」

童年记忆里,纸飞机诞生于课桌上的作业本和草稿纸;而纪录与比赛属于航空史。所以视觉系统由两层构成:

- **主体(折纸/飞行界面)——「作业本」**:米白纸底、方格纸纹理、墨水蓝笔迹、手绘折痕记号、朱红批注;
- **荣誉层(图鉴/挑战赛/纪录墙)——「航空图鉴」**:深蓝夜空、荣誉金徽章、档案卡片排版。

一条原则贯穿始终:**纸是主角**。任何界面装饰都不得比"那张纸"更抢眼。

## 3. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题/文案 | **霞鹜文楷 LXGW WenKai**(OFL 开源) | 手写楷体,作业本质感;Web 需子集化(约 2–5 MB → 按页面分包) |
| 回退 | PingFang SC / Noto Sans SC | 未加载完成时 |
| 数字/参数 | **IBM Plex Mono** | 投掷角度、成绩、坐标,等宽保证对齐 |
| 手绘批注 | LXGW WenKai + 微旋转(±1°) | "老师批注"式提示文案 |

不引入第四种字体。标题不使用粗体堆叠,用字号与颜色分层。

## 4. 图形语言

- **折纸记号采用国际标准**:谷折 = 虚线 + 空心箭头;山折 = 点划线 + 实心箭头(UI 顺便承担折纸科普);
- 纸张渲染:正面 `--paper`,背面纸背灰,折痕叠加层每层加深 8% + 0.4px 错位表现厚度;
- 折痕历史保留为淡蓝虚线(像真的纸上留下的折痕);
- 飞行场景:极简剪影——纸飞机实心墨蓝、云朵单色椭圆、地面草地色块 + 每米刻度;
- 图标:细线手绘风(自绘 SVG,不引图标库),线条 1.5px,端点圆头。

## 5. 动效语言

| 场景 | 规格 |
|---|---|
| 折叠动画 | 800 ms,easeInOutQuad;面片绕折痕轴旋转 + 伪 3D 斜投影(水平偏移 0.32、垂直 0.18) |
| 步骤切换 | 200 ms 淡入,文案先行(第 N 步 · 标题) |
| 飞行 | 真实时间(不加速),相机横向跟随;轨迹淡蓝细线;破纪录时原纪录以灰色幽灵线重放 |
| 破纪录 | 纸屑雨(用色板中的纸色/朱红/墨蓝小纸片),2 s |
| 动画可关 | 尊重 `prefers-reduced-motion`,折叠动画直接跳到终态 |

## 6. 声音(P2)

纸张摩擦(折叠提交时)、风声(随空速变化音量)、落地质感音。全部可静音,默认跟随系统媒体音量。

## 7. 外部风格参考(取意,不抄形)

- **Nintendo Labo**:瓦楞纸/纸板的触感如何通过高光与厚度表达;
- **Alto's Odyssey**:滑翔类游戏的氛围调度——天空渐变、速度感、留白;
- **Origami Simulator(origamisimulator.org)**:工程工具的克制排版,图鉴页可参考其"图形+数据并列"的档案感;
- 传统折纸图解书籍(步骤编号 + 标准记号 + 一句话文案)——我们折纸页的信息架构直接沿用这个几十年验证过的格式。

## 8. 布局与响应式

- 折纸页/试飞页信息架构:顶部步骤条 → 中央画布(占最大面积)→ 底部控制台(单行可换行);
- 320 px 可用:控制台控件换行堆叠,画布保持 4:3 左右;触控目标 ≥ 44 px;
- 图鉴/纪录墙用档案卡片网格(2–3 列自适应),卡片 = 历史照片位(可选)+ 纪录数据 + 一段设计者故事。
