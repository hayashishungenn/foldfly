# 一纸冲天 FoldFly

TypeScript + Vite + Canvas 2D 的网页纸飞机工坊与几何驱动气动模拟。

## 本地运行

```sh
npm install
npm run dev
```

## 验证和构建

```sh
npm test
npm run build
npm run calibrate
npm run calibrate -- --sweep
npm run calibrate -- --convergence
npm run aero-report
npx playwright test   # 浏览器端到端(需系统 Chrome)
```

缺陷台账、基线数据与架构审查记录见 [docs/GOVERNANCE.md](docs/GOVERNANCE.md)(2026-11-26 治理阶段:DOM 注入修复、投掷配置快照、比赛校验与量化排名、状态机集中化、9 路浏览器端到端)。

## 功能与架构概览

0. **自由折纸设计台（`src/fold/freestyle.ts`，Phase 03）**：在任意纸张上点两点画折痕（谷/山、全部层/仅顶层、折后展翼），引擎无法表达的折序会被明确拒绝；设计保存本地、`#design=` 链接分享，产物直接进入几何气动提取与模拟飞行（限自由实验模式）。
1. **真实纸张规格库（`src/paper/papers.ts`）**：
   - 支持 5 种规格：`A4`（210×297 mm）、`US Letter`（215.9×279.4 mm）、`正方形`（150×150 mm）、`A5`（148×210 mm）、`B5`（176×250 mm）；
   - 支持 3 档克重：`70 gsm`、`80 gsm`、`100 gsm`，附带纪录适用说明。
   - **纸张材质库（`src/paper/material.ts`，Phase 01）**：5 种材质（复印纸/高挺激光纸/铜版纸/折纸专用纸/新闻纸）× 克重 → 厚度、紧度、MD/CD 抗弯刚度、各向异性、最小折痕半径、折痕利落度；全部为经验参数库估算（非实测），Phase 01 仅展示与存档，尚未耦合进飞行物理。
2. **七款可交互折叠经典机型（`src/fold/planes/*.ts`）**：
   - **经典尖头机（Classic Dart）**：6 步对称入门折法；
   - **Suzanne（John Collins · 69.14 m 距离纪录）**：11 步宽翼面加厚前缘滑翔机折法；
   - **Mach 5（Dillon Ruble 团队 · 88 m 距离纪录）**：9 步 X-43A 风格工程复刻折法（多折层机头配重、锁头、高机身窄翼展）；
   - **Sky King（户田拓夫 · 27.9 s 滞空纪录）**：19 步大展弦比室内滞空机型折法；
   - **Zero Fighter（户田拓夫 · 29.2 s 滞空历史里程碑，Phase 06）**：19 步工程近似折序（原机锁扣简化），浅机头带配重 + 宽弦机翼，校准 28.98 s；
   - 图鉴每张机型卡附「详情」面板：折序清单、纸张克重×成绩对照、本机个人最佳。
3. **纯逻辑折叠引擎与几何气动提取（`src/fold/`、`src/aero/`）**：
   - 严格无 DOM / Canvas 依赖，支持全栈谷折/山折、局部区域折（`region`）、仅顶层折（`layer: 'top'`）、塞入下层（`tuckUnder`）、翻面（`flip`）、多折痕组合与三维斜翼根展开；
   - `src/aero/extract.ts` 从折后纸层实时积分计算总质量 $m$、重心 $\text{CG}$、展开翼面积 $S$、翼展 $b$、展弦比 $\text{AR}$、四分之一弦气动焦点 $\text{AC}$、俯仰转动惯量 $I_{yy}$、机身侧视面积与浸润面积；
   - `src/aero/integrator.ts` 与 `src/aero/model.ts` 采用 240 Hz 二阶中点法（RK2）积分纵向平面三自由度运动，所有气动配平与阻力极曲线均由无量纲几何特征（翼面饱满度、细长比、展弦比、静稳定裕度）平滑驱动；
   - **折痕质量与材质定形（飞行模型 v4）**：手动折叠的落点偏差聚合为折痕质量 ∈ [0,1]，与材质折痕利落度共同作用于升力/阻力/定形保持通道；完美折痕 + 缺省材质与 v3 轨迹逐位一致，材质与折痕只允许退化或持平（理想几何是上界）。
   - **侧向物理（飞行模型 v5）**：侧滑/偏航/横滚五自由度，风标稳定由重心后龙骨面积×舵臂几何推导；风场升级为顺风+侧风（含确定性阵风），UI 提供侧风滑块与俯视图（弹道投影 + 机头朝向 + 风矢量）；无侧风时逐位复现 v4，校准锚点零漂移。
4. **四大历史标定锚点对照（`npm run calibrate`）**：
   - **经典尖头机**（A4 80g，0° / 20 m/s）：`11.68 m`（参考区间 10–20 m）；
   - **Suzanne**（A4 100g，0° / 28 m/s）：`68.33 m` / `7.94 s`（历史纪录 69.14 m / ~9 s）；
   - **Mach 5**（A4 100g，40° / 28 m/s）：`88.08 m`（历史里程碑 88.31 m，现役 WR 98.43 m）；
   - **Sky King**（A4 80g，20° / 8 m/s）：`29.36 s`（历史纪录 27.9 s / 挑战赛锚点 29.2 s）。
5. **本地锦标赛三项目（`src/game/competition.ts`、`src/game/accuracy.ts`，Phase 07）**：距离赛 / 滞空赛 / **精准着陆赛**（靶线距离由种子确定性生成、同场同靶、距靶偏差低分优排名），Canvas 侧视与俯视均绘制朱红靶线；个人最佳按项目方向（高/低分优）分别保存。
6. **单人生涯模式（`src/game/career.ts`，Phase 08）**：10 关顺序解锁挑战链（距离/滞空/精准/逆风/侧风/材质关），每关锁定纸张与风况、精准关开放角度与力度；关卡种子固定可复现，达标成绩写入本地存档（版本化 + 迁移/重置提示）；全部目标经当前物理校验可达。
7. **成就与纪录墙（`src/game/achievements.ts`，Phase 09）**：11 项成就为幂等纯判定（状态快照 → 解锁集合），数据聚合自自由挑战幽灵/正式赛 PB/生涯存档；生涯主页内置纪录墙（分机型纪录、三项目 PB、成就墙）；里程碑阈值与史实口径一致（69.14 m / 88 m / 20 s / 29.2 s）。
8. **渲染、音效、挑战赛与分享（`src/render/`、`src/game/`、`src/audio/`）**：
   - **三维视图（`src/render/flight3d.ts`，Phase 05，可选）**：Three.js WebGL 展示折叠完成态纸面网格、3D 弹道与姿态（拖拽轨道 + 滚轮缩放）；按需动态加载代码分包，WebGL 不可用自动回退 Canvas 2D；渲染层只消费纯数据，不反哺物理。
   - 遵循 `docs/DESIGN.md`「作业本 × 航空图鉴」视觉规范；
   - 支持距离挑战（88 m）与滞空挑战（29.2 s）、本机最佳幽灵机同屏重放、破纪录纸屑雨动效、URL `#flight=` 确定性配置分享及 Web Audio 程序化折纸/风声/落地音效。
